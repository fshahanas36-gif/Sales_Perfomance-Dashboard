# 📊 Sales Data Analysis & Dashboard – Excel

An interactive **Sales Data Analysis Dashboard built in Microsoft Excel** to analyze sales performance, profit, products, categories, regions, and payment methods.

## 📁 Project Overview

This project uses an Excel sales dataset containing **80 orders** and multiple business attributes such as:

* Order ID
* Order Date
* Customer
* Product
* Category
* Region
* Quantity
* Unit Price
* Discount
* Payment Mode
* Sales
* Cost
* Profit

The data was cleaned and transformed before creating **Pivot Tables and an interactive Excel Dashboard**.

## 📌 Key Analysis

The dashboard provides insights into:

* 💰 Total Sales
* 📈 Total Profit
* 📦 Quantity Sold
* 🛒 Product Performance
* 🗂️ Category-wise Sales
* 🌎 Region-wise Sales
* 💳 Payment Mode Analysis
* 📅 Monthly Sales Trends
* 📊 Profit & Sales Performance

## 🛠️ Tools & Techniques

* **Microsoft Excel**
* Data Cleaning
* Excel Formulas
* Pivot Tables
* Pivot Charts
* Dashboard Design
* Data Visualization
* KPI Analysis

## 🎯 Project Objective

The main objective of this project is to transform raw sales data into an **easy-to-understand business dashboard** that helps identify sales trends, profitable products, regional performance, and other important business insights.

## 📌 Conclusion

This project demonstrates how **Excel can be used to clean, analyze, visualize, and present sales data through an interactive professional dashboard.**
